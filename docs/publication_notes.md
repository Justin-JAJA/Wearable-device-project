# Publication snapshot

This repository is a separate publication copy of the completed local study.
It preserves the three model implementations and completed aggregate estimates.
The original local analysis and full audit outputs remain unchanged.

The publication copy excludes raw workbooks, original participant identifiers,
individual mask/prediction tables, participant linkage metadata, full processed activity matrices, and 700
simulation checkpoints. Example trajectories use stable publication labels.
The activity values themselves are unchanged. Individual trajectories remain
illustrative records, so pseudonym replacement is not a claim of formal anonymity.

The stored Monte Carlo replicate CSV contains the all-activity rows needed for
the interactive report. Full activity-subgroup summaries are retained in the
aggregate summary CSV. Bootstrap confidence intervals and paired comparison
summaries are included; individual bootstrap metrics and paired-difference
replicates are regenerated by a full local run.

The report's completed bootstrap count is read from the saved bootstrap summary.
Its participant totals are read from a two-column aggregate cohort-count CSV;
no individual linkage input is required to rebuild the published report.
By default `render_report.R` reuses included figures. Pass `--refresh-figures`
after a complete local analysis to recompute the eight plots from raw-run outputs.

The synthetic algorithm tests require no participant inputs. Full-study QA needs
the locally generated study data and all checkpoints. Saved QA CSVs record the
successful checks on the original completed run. Publication code and the
aggregate-only report rebuild were checked separately before publication.

No project code license has been selected. Source datasets and bundled third-party
JavaScript/CSS dependencies retain their own terms and notices. Adding a license
later is a separate repository-maintenance decision.
